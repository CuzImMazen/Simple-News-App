# Simple News App

A simple Flutter news app that fetches the latest headlines from the NewsAPI and displays them in a basic UI.

This project was built during my early learning stage of Flutter, so the code is simple and easy to understand.

---

## 🚀 Features

- Fetches top headlines using NewsAPI
- Displays:
  - News title
  - Description
  - Image (if available)
  - Source name
- Category based news
